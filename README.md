# Edu‑Tailwind

**Edu‑Tailwind** adalah proyek website edukasi yang dibangun menggunakan **Tailwind CSS**, berfokus pada antarmuka yang modern, responsif, dan mudah dikembangkan. Proyek ini dapat digunakan sebagai dasar pembuatan platform pembelajaran, halaman kursus, dashboard siswa/guru, atau template pendidikan lainnya.

---

## ✨ Fitur Utama
- UI modern berbasis Tailwind CSS
- Desain responsif di semua perangkat
- Struktur komponen yang mudah dikembangkan
- Navigasi dasar antar halaman
- Optimalisasi CSS dengan Tailwind purge
- Dapat dikembangkan menjadi platform edukasi lengkap

---

## 🧰 Teknologi yang Digunakan
- **Tailwind CSS**
- **HTML**
- **JavaScript**
